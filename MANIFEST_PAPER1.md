# Manifest for Paper 1: manuscript item → script → result file

This file maps every table, figure, appendix and results section of **Paper 1** to the script that produces its numbers and the result file that holds them. Numbering follows **Paper 1 v5 of 15.11.2026** (`manuscript/P10_paper1_v5_2026-11-15.md`: Sections 3.1–4.14, Tables 1–11, Figures 1–4, Appendices A–C). `MANIFEST.md` in this repository maps the numbering of the earlier, longer manuscript (builds v22–v37); its table, section and appendix numbers do not correspond to Paper 1 and should not be used to find Paper 1 items.

How to run: from the repository root, with the pinned environment (`python -m venv .venv`, activate it, `pip install -r requirements.txt`), run `python <script>`. Scripts read the waveform-derived episode files already stored under `results/` and write the result file listed in the same row; the pipeline scripts under `pipeline/` re-download waveforms from EarthScope and are only needed to rebuild the episode files.

Check column: each row was verified on 15.11.2026 by reading the result file. It names at least one number printed in that item of the paper and where it appears (JSON path or line). "derived" means the number is computed from values in the file (shown). Rows or parts marked NOT FOUND say what was searched.
